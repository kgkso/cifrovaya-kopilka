# Цифровая копилка педагогического опыта

Сайт электронной библиотеки колледжа: React + Vite, каталог материалов в JSON, PDF-книги с перелистыванием, административная панель с паролем, Netlify Functions и GitHub Contents API для сохранения публикаций.

## Что реализовано

- Главная страница, каталог, поиск и фильтр по категориям.
- Список авторов и отдельные страницы авторов с их публикациями.
- Страница материала с обложкой, описанием, автором и скачиванием PDF.
- PDF-reader с перелистыванием страниц (react-pageflip + PDF.js).
- Страница «О цифровой копилке».
- Админ-панель: вход по паролю, создание, редактирование и удаление публикаций.
- Данные публикаций хранятся в `public/materials.json`.
- Загруженные файлы сохраняются в `public/uploads/covers` и `public/uploads/books` через GitHub API.

## Локальный запуск (только публичная часть)

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Для полноценной проверки админки нужен запуск через Netlify Dev и настроенные переменные окружения.

## Размещение на Netlify

1. Создайте новый GitHub-репозиторий и загрузите в него все файлы проекта.
2. В Netlify выберите **Add new site → Import an existing project** и подключите репозиторий.
3. Build command: `npm run build`.
4. Publish directory: `dist`.
5. Functions directory: `netlify/functions` (уже указан в `netlify.toml`).
6. В настройках сайта Netlify откройте **Environment variables** и добавьте переменные:

| Переменная | Значение |
|---|---|
| `ADMIN_PASSWORD` | Сложный пароль администратора |
| `SESSION_SECRET` | Случайная длинная строка, минимум 32 символа |
| `GITHUB_TOKEN` | Fine-grained Personal Access Token |
| `GITHUB_OWNER` | Имя владельца GitHub-репозитория |
| `GITHUB_REPO` | Название репозитория |
| `GITHUB_BRANCH` | Ветка, обычно `main` |

7. Для `GITHUB_TOKEN` создайте Fine-grained token только для нужного репозитория и предоставьте разрешение **Contents: Read and write**. Не публикуйте токен и не вставляйте его в исходники.
8. После добавления переменных запустите повторный deploy.

## Важно о безопасности и хранении

- Пароль администратора и GitHub token проверяются/используются только в Netlify Function. Они не передаются браузеру.
- Сессия хранится в HttpOnly, Secure, SameSite=Strict cookie и действует 8 часов.
- Используйте HTTPS (Netlify предоставляет его автоматически).
- Токен GitHub должен иметь доступ только к репозиторию этого сайта.
- Админка отправляет изменения в GitHub. После коммита Netlify запускает новый deploy; обновление публичного сайта может занять некоторое время.
- GitHub — хранилище файлов и JSON, отдельная база данных не используется.
- Для ограничения размера запросов в этом шаблоне установлен лимит 4 МБ на каждый загружаемый файл. Большие PDF предварительно оптимизируйте или уменьшите.
- Удаление публикации удаляет запись из каталога, но оставляет прежние PDF/обложки в GitHub как резерв. Их можно удалить вручную после проверки.
- Для продакшена рекомендуется включить двухфакторную защиту GitHub и ограничить круг администраторов.

## Настройка внешнего вида

Основные цвета, размеры и адаптивные правила находятся в `src/styles.css`. Тексты раздела «О цифровой копилке» редактируются в компоненте `About` файла `src/App.jsx`.

## Замечания перед публикацией

1. Замените демонстрационный текст/названия при необходимости.
2. Проверьте, что ветка GitHub в `GITHUB_BRANCH` совпадает с основной веткой репозитория.
3. Проверьте загрузку PDF и обложки через админку после первого deploy.
4. Убедитесь, что у колледжа есть право размещать выбранные материалы и изображения.
